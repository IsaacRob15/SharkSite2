# SharkSite2

Portfólio pessoal em HTML, CSS e JavaScript puros, sem etapa de build.

## Como abrir

Abra `index.html` no navegador, ou sirva a pasta localmente:

```bash
python3 -m http.server 8000
```

## Como personalizar

- `index.html`: troque "Seu Nome", o texto de "Sobre mim" e as habilidades.
- `script.js`: edite a lista `projects` e o endereço de e-mail do formulário de contato.
- `styles.css`: ajuste as cores nas variáveis de `:root`.
